GitHub Actions

GitHub リポジトリ内でワークフローを自動化する CI/CD プラットフォーム

  • Workflow: .github/workflows/*.yml に定義 (YAML)
  • Trigger: push / pull_request / workflow_dispatch / schedule など
  • Job/Step/Action: job を runner 上で実行
  • Runner: GitHub-hosted / self-hosted を選択
  • Artifacts: 成果物の共有
  • Cache: 依存キャッシュで高速化
  • Secrets: 暗号化管理
  • Environments: デプロイ先ごとに保護ルール
  • セキュリティ: GITHUB_TOKEN 最小権限化 + OIDC
