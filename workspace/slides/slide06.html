GitHub Actions Reusable Workflows

Workflow の共通化/標準化 (DRY) → 再利用

  • 定義: on: workflow_call を宣言
    • inputs / secrets / outputs でインターフェースを固定
  • 呼び出し: jobs.<job_id>.uses で呼ぶ
    • {owner}/{repo}/.github/workflows/{file}@{ref}
    • @ref は commit SHA pin 推奨 (安定性/サプライチェーン対策)
  • 使い分け: reusable workflow は "job/複数 job" の再利用、composite action は "step" の再利用
