GitHub Copilot Coding Agent

GitHub 上で動く自律型 coding agent

  • 機能: 指示に基づき実装/修正し、PR を作成/更新してレビュー依頼まで自動化
    • PR コメントで @copilot をメンションして反復修正を依頼
    • 1 タスク 1 PR、同一リポジトリ内のみ
  • 実行環境: GitHub Actions を利用して独自のエフェメラル開発環境
  • 観測性: セッションログで進捗/実行内容/検証結果を追跡
  • 統制: 起動/フィードバックは write 権限ユーザのみ、push は copilot/ ブランチのみ
  • 類似: Anthropic Claude や OpenAI Codex にも似た機能がある
