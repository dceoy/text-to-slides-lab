Spec-driven Development

仕様 (Spec) を Source of Truth として扱い、コード生成・変更の起点を仕様に置く開発プロセス

  • Spec Kit - GitHub が公開した SDD 用 OSS toolkit (github/spec-kit)
    • /speckit.specify → specs/<feature>/spec.md
    • /speckit.plan → plan.md + research.md / data-model.md など
    • /speckit.tasks → tasks.md (実行可能なタスクリスト)
    • /speckit.implement → 実装を進める

Spec-driven Development vs Plan mode

  • Spec: リポジトリに残る成果物 / Plan: AI の動作モード
  • Spec: 「何を/何故」/ Plan: 「どう進める」
  • Spec を起点に plan/tasks を派生
